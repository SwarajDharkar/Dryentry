# DRYENTRY — Umbrella Dryer Simulator

A self-contained interactive website prototype.

## Run locally
Open `index.html` in a modern browser. No build tools or dependencies are required.

## Publish permanently
1. Create a GitHub repository and upload `index.html`.
2. Import that repository into Vercel (or use Netlify).
3. Deploy. The host will provide a public URL.
4. Optional: connect a custom domain you own.

## Model assumptions
The simulation assigns 35 ml of surface water per umbrella for each rain-intensity level (light=35 ml, medium=70 ml, heavy=105 ml). The selected dryer efficiency is the fraction captured by the machine. This is a demonstration model, not measured engineering performance.
